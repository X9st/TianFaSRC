# Phase 6 进展与验收

## 已实现

- 总览页读取真实任务与健康状态，提供任务、资产、漏洞和模型入口；桌面与手机宽度已做视觉检查。
- 任务详情订阅带事件 ID 的 SSE，断线自动重连，按 ID 去重；保留轮询作为失连时的回退。
- 探索图以可滚动的节点与血缘连线呈现，可选择节点查看摘要和资产锚点。
- Planner 可以给每个 Intent 分配、调整 Worker 预算；服务端硬限制参数，领取任务时固化本次 Run 快照。
- 模型回合和工具调用在服务端原子扣额；Token 使用模型返回值结算。预算用尽时 Worker 进入 exhausted，保留已观察证据。
- 任务详情展示每个 Worker Run 的额度、原因和消耗，无用户预算输入框。
