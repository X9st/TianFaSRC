# ADR-0004：由 Agent 管理每个 Worker 的预算

状态：已采用（2026-11-27）

任务创建和编辑继续不提供预算配置。Planner 可以在创建 Intent 时给出模型回合、工具次数、Token 和最长耗时四项额度及理由，也可以在运行中调整未完成方向。Planner 会看到近期 Worker 的额度和消耗。服务端校验硬上限；未给出时采用保守默认值，同一方向第二次运行起进一步收紧系统默认值。每次 Worker Run 在领取时保存额度快照，模型和工具调用由服务端逐次扣额。Token 用量按模型服务返回值记账，可能在单次调用结束时略超额度；下一次调用会被拒绝。

用户能查看每次 Worker Run 的额度、理由和实际消耗，但不能手动设置。`task_budgets` 只记录任务汇总用量。本决策补充 ADR-0003，取代其中“单次 Worker 固定回合上限”的规则。
