# ADR-0003：移除任务预算配置

状态：已采用（2026-11-26）

用户明确要求删除预算配置项。任务创建与编辑、API 契约、数据库任务字段均不再接受或返回预算；迁移 `000005_phase4.sql` 删除 `tasks.budget`。调度器不再因 Token、费用或工具调用次数达到用户配置阈值而停止任务。

保留 `task_budgets` 表作为历史用量计数器，供模型和工具用量展示与审计使用，不把这些计数解释为额度。任务截止时间、单次 Worker 模型与工具回合上限、工具超时仍属于运行安全边界；达到单次回合上限时可以由 Planner 或用户继续安排工作。

本决策取代原规格中有关“用户可配置预算”“预算耗尽”的要求；其余授权范围、策略、证据与审计要求继续有效。
